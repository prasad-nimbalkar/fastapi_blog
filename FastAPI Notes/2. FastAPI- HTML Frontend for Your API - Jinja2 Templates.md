## 1. Why Use Templates?

- Returning raw HTML strings from Python is messy and unmanageable for full pages.
- Templates let you write proper `.html` files and inject dynamic data into them.
- FastAPI can serve **both**: HTML pages (for browsers) and JSON responses (for API clients) using the same underlying data.

> **Interview Tip:** Always mention that FastAPI supports dual-mode — API routes return JSON, page routes return HTML via templates — both can share the same data source.

## 2. Setup — Jinja2 Templates in FastAPI

### Installation

- If you installed `fastapi[standard]`, Jinja2 is already included — no extra install needed.
- Otherwise: `pip install jinja2`

### Imports

```python
from fastapi import FastAPI, Request
from fastapi.templating import Jinja2Templates
```

- `Request` — required by Jinja2; must be passed to every template route.
- `Jinja2Templates` — points FastAPI to the templates folder.

### Create the Templates Object

```python
templates = Jinja2Templates(directory="templates")
```

- Create a `templates/` folder in your project root.
- All `.html` template files live inside it.

### Return a Template Response

```python
@app.get("/", include_in_schema=False, name="home")
def home(request: Request):
    return templates.TemplateResponse(
        request,
        "home.html",
        {"posts": posts, "title": "Home"}
    )
```

- **First arg:** `request` object.
- **Second arg:** template filename (string).
- **Third arg:** context dictionary — variables accessible inside the template.

> **Important:** `request: Request` must be a parameter in every route that returns a template response. Jinja2 requires it.

## 3. Jinja2 Template Syntax

| Use Case | Syntax |
|---|---|
| Display a variable | `{{ variable }}` |
| For loop | `{% for item in items %} … {% endfor %}` |
| Conditional | `{% if x %} … {% else %} … {% endif %}` |
| Extend a layout | `{% extends "layout.html" %}` |
| Define a block | `{% block content %} … {% endblock content %}` |

- Jinja2 allows **dot notation** to access dictionary keys: `{{ post.title }}` works even if `post` is a Python dict (not just an object).

### Example — Loop + Conditional in a Template

```html
{% if title %}
  FastAPI - {{ title }}
{% else %}
  FastAPI Blog
{% endif %}

{% for post in posts %}
  <h2>{{ post.title }}</h2>
  <p>{{ post.content }}</p>
{% endfor %}
```

## 4. Template Inheritance

- A **parent template** (e.g. `layout.html`) defines the shared HTML structure: head, navbar, footer.
- It marks changeable sections using **blocks**: `{% block content %}{% endblock content %}`
- **Child templates** extend the parent and only fill in their specific blocks.

```html
<!-- layout.html (parent) -->
<body>
  <nav>...</nav>
  {% block content %}{% endblock content %}
  <footer>...</footer>
</body>
```

```html
<!-- home.html (child) -->
{% extends "layout.html" %}
{% block content %}
  {% for post in posts %}
    <h2>{{ post.title }}</h2>
  {% endfor %}
{% endblock content %}
```

> **Important:** Without template inheritance, every page would duplicate the full HTML structure. A change to the navbar would require updating every single file — a maintenance nightmare.

> **Interview Tip:** Mention that you can have multiple named blocks (e.g. `sidebar`, `scripts`, `content`) in the same layout for different override points.

## 5. Serving Static Files

- Static files = CSS, JavaScript, images, icons — files that don't change dynamically.
- FastAPI uses `StaticFiles` from `fastapi.staticfiles`.

```python
from fastapi.staticfiles import StaticFiles

app.mount(
    "/static",                        # URL path
    StaticFiles(directory="static"),  # folder on disk
    name="static"                     # reference name for url_for()
)
```

- Any file in the `static/` folder is now accessible at `/static/filename`.
- Example: `static/css/main.css` → accessible at `/static/css/main.css`.

> **Interview Tip:** `app.mount()` is different from `app.get()` — it mounts an entire ASGI sub-application (`StaticFiles`) at a path prefix, not a single route.

## 6. URL Generation with `url_for()`

Instead of hardcoding URLs in templates, use `url_for()` — it auto-updates if you rename routes or change static paths.

### For Page Routes

```html
<a href="{{ url_for('home') }}">Home</a>
```

- Pass the **route name** (set via the `name=` param on the decorator).

### For Static Files

```html
<link rel="stylesheet" href="{{ url_for('static', path='css/main.css') }}">
```

### Naming Routes Explicitly

```python
@app.get("/", include_in_schema=False, name="home")
@app.get("/posts", include_in_schema=False, name="posts")
```

> **Important:** If two decorators point to the same function and you don't set explicit `name=`, FastAPI can't distinguish them and `url_for()` will resolve to the wrong route.

## 7. Common Interview Questions

**Q: What is Jinja2 and why does FastAPI use it?**
> Jinja2 is a templating engine for Python. FastAPI uses it to render dynamic HTML pages by injecting Python data into HTML files. It's the same engine used by Flask.

---

**Q: What is the context dictionary in a template response?**
> It's a Python dict passed as the third argument to `TemplateResponse`. Every key in this dict becomes a variable you can use inside the template with `{{ variable }}`.

---

**Q: Why is `include_in_schema=False` used on page routes?**
> It hides HTML page routes from the auto-generated API docs at `/docs`. Only JSON API endpoints should appear there — page routes are for browsers, not API consumers.

---

**Q: What is template inheritance and why is it useful?**
> It lets child templates reuse a parent layout (navbar, footer, head) without duplicating HTML. You only maintain the shared structure in one file (`layout.html`), reducing duplication and making updates easier.

---

**Q: How does FastAPI serve CSS and image files?**
> By mounting a `StaticFiles` instance with `app.mount()`. Files in the static directory are then served at the specified URL prefix (e.g. `/static`).

---

**Q: What's the difference between `{{ }}` and `{% %}` in Jinja2?**
> `{{ }}` outputs/displays a value. `{% %}` is for logic/control flow: loops, conditionals, extends, blocks.

## 8. Common Mistakes & Pitfalls

> **Pitfall:** Forgetting `request: Request` as a parameter in the route function — Jinja2 will throw an error.

> **Pitfall:** Using `url_for()` for a route that doesn't exist yet — FastAPI raises a `NoMatchFound` error at runtime. Add routes before referencing them.

> **Pitfall:** Not giving routes explicit `name=` when multiple decorators point to one function — `url_for()` resolves unpredictably.

> **Pitfall:** Mounting static files after defining routes that conflict with `/static` — mount order matters in FastAPI.

> **Pitfall:** Hardcoding static file paths like `/static/css/main.css` instead of using `url_for('static', path=...)` — breaks if you rename the mount path.

---

## 9. Best Practices

- Always use a `layout.html` parent template — never duplicate full HTML structures across pages.
- Pass only what the template needs in the context dict — keep it minimal.
- Use `url_for()` for all links and static file references — never hardcode paths.
- Set `include_in_schema=False` on all HTML page routes to keep API docs clean.
- Name all routes explicitly with `name=` for reliable `url_for()` resolution.
- Keep your static folder organized: `static/css/`, `static/js/`, `static/img/`.
- Maintain separation: API routes return JSON, page routes return `TemplateResponse`.
